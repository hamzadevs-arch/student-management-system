# Portfolio screenshots

Capture **real screenshots from your own running application**, using the fictional demo database only:

1. `dashboard.png` — Overview with cards and charts.
2. `students.png` — Searchable student directory (fictional email addresses).
3. `calendar.png` — Academic calendar populated with fictional events.
4. `reports.png` — Reporting UI (not personal or identifying real data).
5. `assistant.png` — Offline academic assistant answering an authorized fictional-data query.

Use consistent 16:9 or similar dimensions, hide browser personal information, and verify no credentials or real student details appear. Then add these images to your GitHub README with relative Markdown links, e.g.:

`![CampusFlow dashboard](campusflow/docs/screenshots/dashboard.png)`
