# Student Management System

A beginner-friendly Python project for managing student information.

## Features

- Add students
- View all students
- Search for a student
- Update student information
- Delete students
- Exit the application

## Technologies Used

- Python

## Current Version

Phase 1 — Command Line Application

## Project Status

This project is currently under development. More features will be added in future phases.

## Future Plans

- Save student data using JSON
- Add SQLite database
- Use Object-Oriented Programming
- Add student marks and attendance
- Generate performance reports
- Add a graphical user interface
